## Fresh wheel acceptance

Three new virtual environments were created outside the repository and installed only the built wheel, respectively as the base package, the `cite` extra, and the `evaluation` extra.

The base environment proved:

1. `regulatory_harvest` imported as version 0.1.0;
2. `py.typed` and the packaged prompt resources were readable;
3. the OpenAI package was absent, confirming the base install did not pull that optional provider;
4. with provider keys unset and network access directed to a dead proxy, installed `harvest run` completed the copied local example;
5. the run returned `ok: true` and `validation_valid: true`;
6. the exported bundle carried a 64-character canonical self-hash;
7. installed `harvest validate` recomputed the hash, returned no issues, and reported `valid: true`; and
8. two installed `harvest report` invocations freshly validated the bundle and produced byte-identical Markdown.

The cite environment imported `CiteClient` and exposed `harvest cite import` and `harvest cite export`. No live server or mutation was used. The evaluation environment ran installed `harvest eval legalbench-rag` against the repository-owned synthetic fixture and produced one case with micro and macro F1 of 1.0.
